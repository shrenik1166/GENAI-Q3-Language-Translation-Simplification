# AI-Powered Language Translation and Text Simplification

## Project Overview
A Python-based web application that translates academic English text into Marathi, simplifies complex English text, and provides a technical glossary with simple explanations.

## Features
- English-to-Marathi translation using online services
- Beginner-friendly English text simplification
- Technical glossary generation with simple explanations
- Evaluation of meaning, accuracy, and completeness
- Downloadable results in TXT format

## Technologies Used
- Python
- Streamlit
- Pandas
- deep-translator

## Installation

Install the required dependencies:

```bash
python -m pip install -r requirements.txt
```

## How to Run

Start the application using:

```bash
python -m streamlit run app.py
```

Open the local URL displayed in the terminal.

## Project Structure

- `app.py` — Main application code
- `requirements.txt` — Required Python libraries
- `README.md` — Project documentation

## Note
An internet connection is required for online translation. Translation services may occasionally be unavailable or rate-limited.
